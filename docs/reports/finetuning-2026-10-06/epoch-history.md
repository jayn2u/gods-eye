# Complete Epoch History: Primary InfoNCE Run 5aec09de

This appendix records all 60 observed epochs for the primary CUHK-PEDES fine-tuning run. It is separate from demo run 5zouq9g8, which uses AMP, EMA, and gradient checkpointing.

The primary run uses InfoNCE weight 1.0 with in-batch-only negatives, FP32, EMA off, gradient checkpointing off, full-backbone training, and ordinary image augmentation on. Training uses the train split; checkpoint selection uses validation.

The best observed validation text-to-image R@1 is 70.2663% at epoch 57. This is a validation result. The W&B train summary includes test-prefixed values equal to validation values; they do not establish a separate official-test evaluation.

The CSV files retain unrounded metric fractions. This appendix converts retrieval metrics to percent and rounds them to four decimal places; training loss is rounded to six decimals. Global steps are preserved as recorded.

The raw [W&B probe](evidence/pure_probe.json), [configuration](data/pure_run_config.csv), [summary](data/pure_run_summary.csv), [epoch-57 metric table](data/pure_best_epoch_metrics.csv), [wide history](data/pure_training_history_wide.csv), and [long history](data/training_history.csv) are available alongside this appendix.
